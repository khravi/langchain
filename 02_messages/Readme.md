# Messages in LangChain

Messages are the building blocks of conversations in LangChain. They help manage communication between users, AI models, and the system. Each message type has a specific role, making conversations structured, organized, and context-aware.

## Why Messages are Important

Messages are important because they:

- Maintain conversation history and context.
- Help the AI understand previous interactions.
- Enable multi-turn conversations.
- Separate user inputs, AI responses, and system instructions clearly.
- Improve response accuracy and conversational flow.
- Allow developers to control AI behavior using system prompts.
- Make chatbot and AI agent development easier and more scalable.

Without messages, the model would treat every request independently and lose the context of the ongoing conversation.

---

# Common Message Types

## 1. HumanMessage

Represents a message from a human user.

### Purpose
Used to send user input or queries to the AI model.

### Example 
```python
from langchain_core.messages import HumanMessage

HumanMessage(content="What is LangChain?")
```
## 2. AIMessage

Represents a response generated by the AI model.

### Purpose

Used to store or represent the model's reply.

### Example

```Python
from langchain_core.messages import AIMessage

AIMessage(content="LangChain is a framework for building LLM applications.")
```

## 3. SystemMessage

Represents instructions or context provided to the AI model.

## Purpose

Used to guide model behavior, tone, rules, or restrictions.

## Example
```python
from langchain_core.messages import SystemMessage

SystemMessage(content="You are a helpful AI assistant.")

```
## Why We Need Messages in LangChain

In LangChain, messages are needed to:

1. Build conversational AI applications.
2. Create chatbots with memory.
3. Manage chat history effectively.
4. Pass structured conversation data to chat models.
6. Enable AI agents to reason using previous interactions.
7. Maintain role-based communication between system, user, and AI.

Messages provide a standardized format that chat models can understand easily.

Example Conversation Flow
from langchain_core.messages import HumanMessage, AIMessage, SystemMessage

messages = [
    SystemMessage(content="You are a helpful assistant."),
    HumanMessage(content="What is Python?"),
    AIMessage(content="Python is a programming language.")
]

In this example:

SystemMessage sets the assistant behavior.
HumanMessage contains the user query.
AIMessage contains the AI response.
