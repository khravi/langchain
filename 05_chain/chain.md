markdown_content = """# LangChain Chains Overview

## What is a Chain?
In LangChain, a **chain** is a sequence of automated actions strung together to accomplish a specific AI task. It acts as the core mechanism that connects a Large Language Model (LLM) with other components—like data sources, prompts, and parsers—allowing information to flow smoothly from a user's input to the final structured output.

## The Building Blocks of a Basic Chain
At its simplest, a chain usually consists of three core components:

1. **Prompt Template:** Takes the raw user input and formats it into a structured prompt with specific instructions for the LLM.
2. **LLM:** The language model itself (like OpenAI's GPT-4 or Anthropic's Claude), which receives the prompt and generates a text response.
3. **Output Parser:** Takes the raw text generated by the LLM and formats it into a usable structure (like a Python dictionary, a JSON object, or a clean string).

## LCEL (LangChain Expression Language)
LCEL is the modern, standard way to build chains in LangChain. It uses a declarative syntax and the Python pipe operator (`|`) to chain components together, making workflows highly modular and easy to read.

### Example LCEL Implementation
```python
from langchain_core.prompts import PromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

# 1. Define the components
prompt = PromptTemplate.from_template("Tell me a short joke about {topic}")
model = ChatOpenAI(model="gpt-4")
parser = StrOutputParser()

# 2. Build the chain using the pipe operator
chain = prompt | model | parser

# 3. Execute the chain
result = chain.invoke({"topic": "data engineers"})
print(result)
```
